# TalkType —— Mac 上免费、离线的语音输入

*[English](README.md)*

![TalkType logo](docs/assets/talktype-logo.png)

**用说的，代替打字。** 在 Mac 上任何地方按一下快捷键，把想说的说出来，再按一下 —— 文字就出现在光标的位置。Slack 里、备忘录里、邮件里、终端里都行。凡是能打字的地方，都能说。

所有处理都在**你自己的电脑上**完成。你的声音不会被上传、不会被保存、也不会拿去训练任何东西。不用注册账号，没有订阅，不收月费。TalkType 是免费的开源软件。

它是一个中英混说的人做给自己用的，所以**一句话里中英文混着说，它就是能听懂** —— 你不用切换语言，说到哪算哪。

```
按快捷键  ──►  说话  ──►  再按一下  ──►  文字出现在光标处
                                          大约一秒后
```

## 下载

**[⬇ 下载最新版本](https://github.com/simonsysun/talktype/releases/latest)** —— 解压，把 `TalkType.app` 拖进"应用程序"文件夹，打开它。

需要一台 **Apple 芯片的 Mac**（M1 或更新），系统 **macOS 13 以上**。

第一次打开时 macOS 会拒绝，因为 TalkType 没有花钱买苹果的开发者证书。免费开源软件基本都这样。**右键点 App ▸ 打开 ▸ 打开**，之后 macOS 就记住了。

然后设置窗口会带你走三步：

1. **语音引擎** —— 点 Install。会下载大约 4 GB，只下这一次。这就是把你的声音变成文字的东西，它住在你自己的电脑上。
2. **权限** —— macOS 会要麦克风权限，以及"允许帮你粘贴"的权限。两个都必须给，TalkType 没法替你同意。
3. **云端润色**（可选，不想要就跳过）—— 见下文。

好了。按 **⌘⇧Space** 开始说。

## 常见问题

**真的免费吗？**
真的。不用账号，不用订阅，也没有试用期。代码在这里，MIT 协议。

**我的声音会被传到哪里去吗？**
不会。语音识别在你的 Mac 上跑。把可选的润色关掉之后，TalkType 完全不联网 —— 在飞机上也能用。

**那"云端润色"是什么？**
一个可选的附加功能，用来整理**文字**：去掉"呃""嗯"，补标点，以及你说到一半改口时把话理顺。它发送的是转写出来的文字，**从不发送音频**，发给 [Groq](https://console.groq.com/keys)。不填 key 它就是关的，而且本地有一套规则化的清理兜底，效果也不差。

**支持中文吗？中英文混着说呢？**
支持，而且这正是做它的初衷。它自己判断语言 —— 你从来不用告诉它接下来要说哪种，句子中间切换也行。

**有多快？**
你停止说话之后大约 0.3–0.9 秒。因为不用上传，在同一批录音上它比测过的十四个云端转写服务都快。

**会不会拖慢我的 Mac？**
语音模型加载时占大约 4 GB 内存，五分钟不用 TalkType 就会把它释放掉。再用时四分之一秒就回来了。App 和引擎都不会随使用时间变胖。

**更新之后就不粘贴了，怎么回事？**
macOS 把"允许这个 App 粘贴"这个权限，绑定在它当初批准的那个**确切版本**上。TalkType 没有付费证书，所以新版本在 macOS 眼里就是另一个 App —— 尽管系统设置里 TalkType 的开关看上去还是开着的。TalkType 会发现这件事，并给你一个 **Fix This** 按钮；点它，然后在 macOS 询问时把 TalkType 重新打开就好。

*（从 v2.0.2 起，发布版本用同一张证书签名，所以这个问题在以后的更新里不会再出现。）*

**需要懂技术吗？**
不需要。下载、打开、点 Install、同意两个权限。

| | TalkType | 苹果自带听写 | Wispr Flow / Superwhisper |
|---|---|---|---|
| 价格 | 免费 | 免费 | 订阅制 |
| 离线可用 | 是 | 部分 | 通常要联网 |
| 声音离开电脑 | 从不 | 有时 | 通常会 |
| 中英混说 | 支持 | 很差 | 看产品 |
| 去掉口头禅 | 会 | 不会 | 会 |
| 自定义词库 | 有 | 有限 | 有 |
| 开源 | 是 | 否 | 否 |

如果你想要打磨得更精致、有客服、背后有公司的产品，去买那些付费的 —— 它们做得很好。TalkType 的存在是为了那些想要同样的东西、但不想付订阅费、也不想让自己的声音进别人服务器的人。

## 它能做什么

- 用 **⌘⇧Space** 在任何地方开始口述 —— 快捷键可以改
- 直接粘贴进你原来在用的那个 App；中途切走了它还会把你送回去
- 中英混说不用提前告诉它
- **自定义词库**，专治它老是听错的人名、缩写和产品名
- 指定某个麦克风，或者跟随系统当前在用的
- 安静一段时间后自动停止
- 待在菜单栏里；没有 Dock 图标，不占你的屏幕

## 技术细节

语音识别用的是 [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR)，通过 [MLX](https://github.com/ml-explore/mlx) 跑在你 Mac 的 GPU 上。TalkType 用一个小的 Python 辅助进程把它常驻在内存里，这样口述时不用等模型加载；这个进程只绑定本地回环地址，以 `HF_HUB_OFFLINE=1` 运行，TalkType 退出时它也退出。

```
说话 ──► 本地 Qwen3-ASR ──► 可选云端润色 ──► 粘贴进当前 App
          0.3–0.9 秒          0.2 秒
          在本机               只发文字，从不发音频
```

**隐私，说清楚：**

| | 会离开你的电脑吗？ |
|---|---|
| 音频 | 从不 |
| 转写文字 | 只有你开了润色才会，而且只发给 Groq |
| 自定义词库 | 给本地模型；从不发给 Groq |

**词库是有极限的。** 你加的词会影响模型的拼写倾向，之后也用于保守的纠正 —— 只有足够独特的词（`API`、`GPT-4o`、`TalkType`）会被自动纠正，普通词永远不会。`TestFlight` 能从"test flight"救回来；`xAI` 从"what's a ship"救不回来，因为这两个念起来几乎一样，加多少词库都没用。

**菜单栏：**

| 项目 | 作用 |
|---|---|
| Speech engine | 本地模型是已加载、加载中、还是没装 |
| Polish with cloud AI | 开关云端润色；关掉就一切留在本机 |
| Groq API Key… | 添加、更换、删除 key（存在你的登录钥匙串里） |
| Microphone | 指定输入设备，或者自动 |
| Vocabulary | 用来纠偏的词 |
| Change Hotkey… | 会检测和系统快捷键的冲突 |
| Setup… | 随时再打开首次设置窗口 |

## 从源码构建

```bash
git clone git@github.com:simonsysun/talktype.git
cd talktype

./asr/install.sh                 # Python 环境 + Qwen3-ASR 权重，装到 ~/.talktype/asr
                                 # ./asr/install.sh 0.6B 用更小但更不准的模型

./scripts/make-signing-cert.sh   # 可选，只需一次：让权限在更新后依然有效
./scripts/build.sh install
```

`swift test` 不用 Xcode 就能跑逻辑测试。`TODO.md` 记录着做完了什么、还没做什么。

仓库里有一个 iOS 键盘扩展，但从来没有编译过，目前搁置。
