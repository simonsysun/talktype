# TalkType —— 用说的，代替打字

*[English](README.md)*

![TalkType logo](docs/assets/talktype-logo.png)

**用说的，代替打字。** 在 Mac 上任何地方按一下快捷键开始说，再按一下（或停顿）——文字就落在光标处。Slack、备忘录、邮件、终端……凡是能打字的地方，都能说。

这是一个中英混说的人做给自己用的软件，所以**一句话里中英文混着说，它就是能听懂**——你不用切换语言，说到哪算哪。

```
按快捷键 → 说话 → 再按一下 / 停顿 → 文字出现在光标处
```

## 双引擎，一条快捷键

TalkType 有两种把你的声音变成文字的方式，并且自动帮你选：

| 引擎 | 是什么 | 什么时候用 |
|---|---|---|
| **云端**（默认） | 通过 [OpenRouter](https://openrouter.ai) 调用 Qwen3-ASR-Flash——中英混说准确，一次听写约 2 秒，每天说 30 分钟约 $2/月 | 有网的时候 |
| **本地** | 你自己 Mac 上的 Qwen3-ASR（MLX）——0.3–0.9 秒，音频不出机器，下载约 4 GB | 没网、或云端连不上的时候 |

默认走云端，是为了把 Mac 的内存省下来。没网（或云端挂了）时，TalkType **会自动切到本地引擎，并明确告诉你切换了**——在飞机上也能继续听写。如果本地没装、网也没有，它会直接说清楚，而不是默默地失败。

**隐私，说精确点：**

| 什么 | 会离开你的 Mac 吗 |
|---|---|
| 音频 + 当前词库提示（云端引擎） | 会——发给 OpenRouter，按它的数据政策处理 |
| 音频（本地引擎） | 不会 |
| 文字 + 当前词库 → 润色（可选） | 只发文字给 Groq——从不发音频 |

没有账号、没有遥测、没有订阅。唯一的凭证是你自己的 API key（OpenRouter 识别 + 可选的 Groq 润色），存在 macOS 钥匙串里。

## 快速上手——大约 5 分钟

**你需要：** Apple 芯片 Mac（M1 及以上），macOS 13 以上。

1. **下载并打开。** [⬇ 下载最新版](https://github.com/simonsysun/talktype/releases/latest)——解压，拖进"应用程序"。第一次打开 macOS 会拒绝——免费软件没买付费证书。右键点 App ▸ **打开** ▸ **打开**，之后它就记住了。
2. **给两个权限。** 麦克风，以及"允许帮你粘贴"。两个都必须给，TalkType 没法替你同意。
3. **填你的 OpenRouter key。** 设置 ▸ 粘贴 key（在 [openrouter.ai/keys](https://openrouter.ai/keys) 获取；充几美元，正常用能撑一两个月）。云端听写立刻可用。
4. **可选：装本地引擎。** 设置 ▸ 本地引擎 ▸ **安装**——下载约 4 GB，只下一次。只有想离线用、或希望音频完全不出机器时才需要。
5. **可选：填一个 Groq key 做润色。** 设置 ▸ 云端润色 ▸ 粘贴 key（在 [console.groq.com/keys](https://console.groq.com/keys) 免费获取）。润色去"呃嗯"、补标点——只发文字，从不发音频。不填也有本地规则兜底。

按 **⌘⇧Space** 开始说。

## 使用手册

- **快捷键**——默认 ⌘⇧Space；在菜单栏"更改快捷键…"里改。
- **麦克风**——指定一个，或选自动（跟随系统默认，包括蓝牙耳机；用蓝牙麦录音时链路切到耳机模式，播放会降到 24kHz 单声道一段时间）。
- **词库**——把模型老听错的名字和术语加进去。OpenRouter 目前会忽略语音引擎的提示字段，所以 TalkType 也会把这些词作为“标准拼写”交给可选润色——只有原文明确说到时才能使用——最后再在本地做一次保守的拼写纠正。
- **引擎**——菜单栏 ▸ 语音引擎 ▸ 云端 / 本地。默认云端，菜单里能看到当前用哪个。
- **本地引擎**——设置里可安装/重装；红色"删除本地引擎…"按钮可释放约 4 GB，不需要离线听写时再删。
- **Key**——设置里可添加、更换、删除；都存在登录钥匙串里。
- **剪贴板**——每段转写也会留在剪贴板上，⌘V 永远是兜底。
- **离线**——TalkType 会自动切本地引擎，并在切换时通知你。本地没装、网也没有时，它会告诉你"装本地引擎或联网"。

## 常见问题

- **更新之后不粘贴了？** macOS 把"允许粘贴"权限绑定在具体版本上，TalkType 没有付费证书，所以新版本在 macOS 眼里是另一个 App。TalkType 会自己发现并给你 **Fix This** 按钮；点它，然后在 macOS 询问时重新打开 TalkType。（v2.0.2 起共用一张证书签名，以后更新不会再这样。）
- **提示"云端语音引擎没有 API key"？** 去设置里填 OpenRouter key。
- **云端感觉慢？** 云端每次听写大约多 2 秒。如果你更在乎速度和隐私、不在乎内存，就切到本地引擎。
- **提示"云端模型不可用"？** TalkType 用的是 OpenRouter 上的固定 Qwen 快照。万一 OpenRouter 下线了它，
  可以在 `~/.talktype/config.json` 里设置 `"cloud_model_override": "新模型名"` 然后重启，或更新 TalkType 获取新默认。

## 内部实现

- **云端：** 通过 OpenRouter 的 `/audio/transcriptions` 调 Qwen3-ASR-Flash（base64 WAV）。默认引擎——约 2 秒，约 $0.002/分钟，音频会离开机器。
- **本地：** 通过 [MLX](https://github.com/ml-explore/mlx) 跑 Qwen3-ASR，是一个只监听本机回环的小 Python 辅助进程，随 App 退出。加载时约占 4 GB 内存。
- **润色：** [Groq](https://groq.com) 上的 Qwen——约 0.3 秒，只发文字，并有严格护栏防止改写或翻译你说的话；本地规则在润色关闭或失败时兜底。

## 从源码构建

```bash
git clone https://github.com/simonsysun/talktype.git
cd talktype

./asr/install.sh                 # Python 环境 + Qwen3-ASR 权重，装到 ~/.talktype/asr
                                 # ./asr/install.sh 0.6B 换更小但略差的模型

./scripts/make-signing-cert.sh   # 可选，一次：让权限在更新后仍然有效
./scripts/build.sh install
```

`swift test` 不需要 Xcode 就能跑逻辑测试。`TODO.md` 记录做完了什么、还差什么。仓库里还有一个从未编译、暂时搁置的 iOS 键盘扩展。
