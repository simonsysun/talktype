# Simon's Development Log

## Document Contract

`DEVLOG.md` is Simon's personal development log for TalkType.

**This file does:**

- record, in human language, what advanced, what was noticed, and open questions;
- preserve voice and mixed Chinese/English as Simon prefers;
- provide optional material for personal review or short updates.

**This file does not:**

- define the product; see [PRODUCT.md](./PRODUCT.md);
- record formal decisions; see [DECISION.md](./DECISION.md);
- replace the task tracker; see [NOW.md](./NOW.md);
- act as agent instructions, completion proof, or technical source of truth;
- store secrets, API keys, or unnecessary personal data;
- auto-collect every agent session.

Agents may read this file when Simon's personal perspective is load-bearing.
Agents must not add, rewrite, or polish entries unless Simon explicitly asks.
When asked to polish, keep Simon's facts, judgment, uncertainty, and voice.

## How to write

- Newest date first.
- One short paragraph per entry; no forced template.
- Label unconfirmed items as ideas, questions, or possible next steps.
