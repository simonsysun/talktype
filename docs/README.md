# docs/

Narrow technical or asset references that still have a current consumer.

**This directory does:**

- hold assets linked from user-facing docs (e.g. `assets/talktype-logo.png`);
- hold other implementation references only when live code or maintainers depend on them.

**This directory does not:**

- store product contracts, decisions, task state, or research synthesis;
- act as a landfill for old plans or ADRs.

Decisions live only in root [`DECISION.md`](../DECISION.md). Do not recreate
`docs/adr/` or a second decision log. `PRODUCT.md` wins any product-level conflict.
